How to use

Choose a structure and operation, enter a value, and tap Perform operation. For graph edges, type two vertex names separated by a comma, such as A,B. BFS and DFS start from the vertex name you enter.

A plain binary search tree can become unbalanced: its operations are O(h), with O(log n) average and O(n) worst case. Graph traversal uses an adjacency list and takes O(V + E).
